Every request returns readonly DTOs — immutable objects with typed, public properties.
Timestamps are always `DateTimeImmutable`. A nullable property (`?`) means Steam omitted
the field, never that decoding failed; where an absent field would be ambiguous the SDK
raises a [domain exception](/php-steam-api-sdk/guide#exceptions) instead.

## Friend

Returned by [`GetFriendListRequest`](/php-steam-api-sdk/api-reference#getfriendlistrequest).

| Property | Type | Notes |
| --- | --- | --- |
| `steamId` | `SteamId` | The friend's 64-bit ID. |
| `relationship` | `FriendRelationship` | Relationship to the queried user. |
| `friendSince` | `DateTimeImmutable` | When the friendship was formed. |

## OwnedGame

Returned by [`GetOwnedGamesRequest`](/php-steam-api-sdk/api-reference#getownedgamesrequest).

| Property | Type | Notes |

| `playtimeForever` | `int` | Total playtime, in minutes. |

| Property | Type | Notes |
| --- | --- | --- |

| `achievements` | `list<PlayerAchievement>` | Per-achievement state. |

Each `PlayerAchievement` carries:

| Property | Type | Notes |
| --- | --- | --- |
| `apiName` | `string` | Stable API identifier. |
| `achieved` | `bool` | Whether it is unlocked. |
| `unlockedAt` | `?DateTimeImmutable` | Unlock time, `null` if locked. |
| `name` | `?string` | Display name (needs `language`). |

## PlayerBan

Returned by [`GetPlayerBansRequest`](/php-steam-api-sdk/api-reference#getplayerbansrequest).

| Property | Type | Notes |
| --- | --- | --- |
| `steamId` | `SteamId` | The player's 64-bit ID. |
| `isCommunityBanned` | `bool` | Banned from Steam Community. |
| `isVacBanned` | `bool` | Has an active VAC ban. |
| `numberOfVacBans` | `int` | Total VAC bans on record. |
| `numberOfGameBans` | `int` | Total developer-issued game bans. |
| `daysSinceLastBan` | `int` | Days since the most recent ban. |
| `economyBan` | `EconomyBan` | Trade/market ban status. |

<Aside type="caution" title="daysSinceLastBan is 0 for clean accounts">
Steam reports `0` both for a ban issued today and for a player never banned at all —
read it together with `numberOfVacBans` and `numberOfGameBans`.
</Aside>

| `hasCommunityProfile` | `bool` | Player has set up a community profile. |
| `commentPermission` | `CommentPermission` | Who may comment on the profile. |
| `personaState` | `PersonaState` | Online / away / offline, etc. |
| `realName` | `?string` | Real name, if shared. |
| `primaryClanId` | `?string` | Primary group ID, if any. |
| `timeCreated` | `?DateTimeImmutable` | Account creation time, if exposed. |
| `lastLogOff` | `?DateTimeImmutable` | Last logout, if exposed. |
| `gameId` | `?string` | App ID currently being played. |
| `gameExtraInfo` | `?string` | Title of the game being played. |
| `gameServerIp` | `?string` | Game server address, if in-game. |
| `countryCode` | `?string` | ISO country code, if shared. |
| `stateCode` | `?string` | State/region code, if shared. |
| `cityId` | `?int` | Steam city ID, if shared. |

<Aside type="caution" title="A hidden profile arrives stripped">
When `communityVisibility` is `Hidden`, Steam sends only the identity and avatar fields —
`timeCreated`, `realName`, `primaryClanId`, `countryCode`, `stateCode` and `cityId` all come
back `null`, and a mixed batch returns those summaries alongside the public ones.
</Aside>

| Property | Type | Notes |
| --- | --- | --- |

## Enums

Three of these mirror Steam's wire values; `CommentPermission` and `EconomyBan` do not,
and those are the two worth reading before you `match` on them.

### CommentPermission

Backed by `string` — `Everyone` (`'everyone'`), `Nobody` (`'nobody'`), `FriendsOnly`
(`'friends_only'`). Steam sends `commentpermission` as an **integer** and omits it
entirely for the friends-only case, so these backing values are the SDK's own vocabulary
rather than the wire values. Use `fromApiValue()` to map from a raw payload.

### CommunityVisibility

Backed by `int` — `Hidden` (`1`), `Visible` (`3`). Steam's own `communityvisibilitystate`
codes; those two are the only ones the live API returns.

### EconomyBan

Backed by `string` — `None` (`'none'`), `Probation` (`'probation'`), `Banned`
(`'banned'`), `Unknown` (`'unknown'`). Steam documents only `none` and `probation` before
trailing off with "and so forth" — `banned` is observed on live accounts but
undocumented, so the value set is provably open.

### FriendRelationship

Backed by `string` — `All` (`'all'`), `Friend` (`'friend'`). The values Steam accepts on
the `relationship` query parameter.

### PersonaState

Backed by `int`, using Steam's own `personastate` codes.

| Case | Value |
| --- | --- |
| `Offline` | `0` |
| `Online` | `1` |
| `Busy` | `2` |
| `Away` | `3` |
| `Snooze` | `4` |
| `LookingToTrade` | `5` |
| `LookingToPlay` | `6` |

<Aside type="caution" title="Only EconomyBan has an escape hatch">
`EconomyBan::fromApiValue()` maps anything unrecognised to `Unknown`, so a new ban state
from Valve cannot break callers. The other two helpers — on `CommentPermission` and
`CommunityVisibility` — treat their set as closed and throw `UnexpectedValueException`.
</Aside>
