Every request returns readonly DTOs — immutable objects with typed, public properties.
Timestamps are always `DateTimeImmutable`. A nullable property (`?`) means Steam omitted
the field, never that decoding failed; where an absent field would be ambiguous the SDK
raises a [domain exception](/php-steam-api-sdk/guide#exceptions) instead.

## AppNews

Returned by [`GetNewsForAppRequest`](/php-steam-api-sdk/api-reference#getnewsforapprequest).

| Property | Type | Notes |
| --- | --- | --- |
| `appId` | `int` | The app ID you asked for. |
| `items` | `list<NewsItem>` | The page, newest first, capped by `count`. |
| `total` | `int` | Items matching the filters up to `endDate`, ignoring `count`. |

Each `NewsItem` carries:

| Property | Type | Notes |
| --- | --- | --- |
| `id` | `string` | Steam's `gid`, unique per item. |
| `title` | `string` | Headline. |
| `url` | `string` | Link to the post. |
| `isExternalUrl` | `bool` | Steam's own flag; `false` for posts hosted on the Steam store. |
| `author` | `?string` | Byline; `null` when the feed names none. |
| `contents` | `string` | Body in the feed's own markup, BBCode or HTML, or a flattened excerpt with `maxLength`. |
| `feedLabel` | `string` | Display name of the feed, such as `Community Announcements`. |
| `feedName` | `string` | The name `feeds` filters on, such as `tf2_blog`. |
| `isCommunityAnnouncement` | `bool` | Whether the post is an announcement from the game's Steam community hub. |
| `publishedAt` | `DateTimeImmutable` | Publication time. |
| `appId` | `int` | The app the post belongs to: the base game for a DLC, or another app sharing the feed. |
| `tags` | `list<string>` | Tags on the post, such as `patchnotes`; empty when it has none. |

## GameSchema

Returned by [`GetSchemaForGameRequest`](/php-steam-api-sdk/api-reference#getschemaforgamerequest).

| Property | Type | Notes |
| --- | --- | --- |
| `gameName` | `?string` | Game title. Null when Steam sends it blank or leaves it out. |
| `gameVersion` | `?string` | Steam's own version counter for the schema. |
| `stats` | `list<SchemaStat>` | Every stat the game publishes. |
| `achievements` | `list<SchemaAchievement>` | Every achievement the game publishes. |

Each `SchemaAchievement` carries:

| Property | Type | Notes |
| --- | --- | --- |
| `apiName` | `string` | Stable API identifier, same one `PlayerAchievement` carries. |
| `name` | `string` | Display name, localised by `language`. |
| `description` | `?string` | Localised description. Steam omits it on some achievements, hidden ones especially. |
| `hidden` | `bool` | Steam keeps the achievement secret until it is unlocked. |
| `icon` | `string` | Icon shown once unlocked. |
| `iconGray` | `string` | Icon shown while locked. |

`SchemaStat` has `apiName` (`string`), `name` (`?string`, null for the many stats Steam
ships unlabelled) and `defaultValue` (`int|float`).

## PlayerBadges

Returned by [`GetBadgesRequest`](/php-steam-api-sdk/api-reference#getbadgesrequest).

| Property | Type | Notes |
| --- | --- | --- |
| `badges` | `list<Badge>` | Every badge the account has earned. |
| `playerXp` | `int` | Total experience on the account. |
| `playerLevel` | `int` | Steam community level. |
| `xpNeededToLevelUp` | `int` | Experience still missing for the next level. |
| `xpNeededForCurrentLevel` | `int` | Experience the current level started at. |

Each `Badge` carries:

| Property | Type | Notes |
| --- | --- | --- |
| `badgeId` | `int` | Steam's badge ID, unique only together with `appId`. |

| `level` | `int` | Badge level. |
| `completedAt` | `DateTimeImmutable` | When the badge was earned. |
| `xp` | `int` | Experience the badge contributes to `playerXp`. |
| `communityItemId` | `?string` | Community item ID, `null` outside trading cards. |
| `borderColor` | `?int` | Steam's border code, `null` outside trading cards. |
| `scarcity` | `int` | How many accounts hold this badge. |

`cityId` all come back `null`, and a mixed batch returns those summaries alongside the public
ones.
</Aside>

## SdrConfig

Returned by [`GetSdrConfigRequest`](/php-steam-api-sdk/api-reference#getsdrconfigrequest).

| Property | Type | Notes |
| --- | --- | --- |
| `revision` | `int` | Valve's revision of the network map, the same for every app ID. |
| `pointsOfPresence` | `array<string, SdrPointOfPresence>` | Keyed by each point of presence's code. |

Each `SdrPointOfPresence` carries:

| Property | Type | Notes |
| --- | --- | --- |
| `code` | `string` | Valve's short code, such as `waw` or `bom2`. |
| `description` | `string` | Location, and the hosting provider where it is not Valve. |
| `latitude` | `float` | As Valve sends it. |
| `longitude` | `float` | As Valve sends it. |
| `aliases` | `list<string>` | Other codes that name the same point of presence. |
| `relays` | `list<SdrRelay>` | Empty for a point of presence that only routes. |

`SdrRelay` has `ipv4` (`string`), and `minPort` and `maxPort` (`int`), the ends of the port
range it answers on.

<Aside type="caution" title="Coordinates arrive unchecked">
A few do not match their description: `dsto`, labelled Stockholm, sits in Moscow, and `dlhr`
has latitude and longitude swapped. The SDK passes them through as Valve sends them.
</Aside>

## Enums

Five of these mirror Steam's wire values; `CommentPermission` and `EconomyBan` do not,
and those are the two worth reading before you `match` on them.

### CommentPermission

Backed by `string` — `Everyone` (`'everyone'`), `Nobody` (`'nobody'`), `FriendsOnly`
(`'friends_only'`). Steam sends `commentpermission` as an **integer** and omits it
entirely for the friends-only case, so these backing values are the SDK's own vocabulary
rather than the wire values. Use `fromApiValue()` to map from a raw payload.

### CommunityVisibility

Backed by `int` — `Hidden` (`1`), `FriendsOnly` (`2`), `Visible` (`3`). Steam's own
`communityvisibilitystate` codes; Valve documents only `1` and `3`, but `2` comes back for
profiles set to friends only.

### EconomyBan

Backed by `string` — `None` (`'none'`), `Probation` (`'probation'`), `Banned`
(`'banned'`), `Unknown` (`'unknown'`). Steam documents only `none` and `probation` before
trailing off with "and so forth" — `banned` is observed on live accounts but
undocumented, so the value set is provably open.

### FriendRelationship

Backed by `string` — `All` (`'all'`), `Friend` (`'friend'`). The values Steam accepts on
the `relationship` query parameter.

### Language

Backed by `string`, using Steam's codes for the `l` query parameter. They are not ISO
codes, so five cases are named for the language and backed by Valve's spelling of it:

| Case | Value |
| --- | --- |
| `ChineseSimplified` | `'schinese'` |
| `ChineseTraditional` | `'tchinese'` |
| `Korean` | `'koreana'` |
| `PortugueseBrazil` | `'brazilian'` |
| `SpanishLatinAmerican` | `'latam'` |

The other twenty-five back onto their own name lowercased: `Arabic`, `Bulgarian`, `Czech`,
`Danish`, `Dutch`, `English`, `Finnish`, `French`, `German`, `Greek`, `Hungarian`,
`Indonesian`, `Italian`, `Japanese`, `Norwegian`, `Polish`, `Portuguese`, `Romanian`,
`Russian`, `Spanish`, `Swedish`, `Thai`, `Turkish`, `Ukrainian`, `Vietnamese`.

Set one per call, or [once on `SteamConfig`](/php-steam-api-sdk/configuration#default-language).

### PersonaState

Backed by `int`, using Steam's own `personastate` codes.

| Case | Value |
| --- | --- |
| `Offline` | `0` |
| `Online` | `1` |
| `Busy` | `2` |
| `Away` | `3` |
| `Snooze` | `4` |
| `LookingToTrade` | `5` |
| `LookingToPlay` | `6` |

### ServerRegion

Backed by `int`, using Steam's `region` codes, which a game server sets with `sv_region`.

| Case | Value |
| --- | --- |
| `World` | `-1` |
| `UsEast` | `0` |
| `UsWest` | `1` |
| `SouthAmerica` | `2` |
| `Europe` | `3` |
| `Asia` | `4` |
| `Australia` | `5` |
| `MiddleEast` | `6` |
| `Africa` | `7` |

<Aside type="caution" title="Two helpers never throw">
`EconomyBan::fromApiValue()` maps anything unrecognised to `Unknown` and
`ServerRegion::fromApiValue()` to `World`, so a new value from Valve cannot break callers. The
other two, on `CommentPermission` and `CommunityVisibility`, treat their set as closed and throw
`UnexpectedValueException`.
</Aside>
