A framework-agnostic PHP SDK for the [Steam Web API](https://steamcommunity.com/dev),
built on top of [Saloon](https://docs.saloon.dev/) v4. Every request returns a
strongly-typed, readonly DTO — you never touch raw JSON, and a malformed profile
fails with a domain exception instead of a silent `null`. It powers the player profiles
on [Dead by Stats](https://deadbystats.eu).

## Why php-steam-api-sdk

- **Fluent resources** — `$connector->players()->ownedGames($id)`, no request classes to import.
- **Strongly typed** — PHP 8.5, PHPStan max, 100% type coverage.
- **Readonly DTOs** — immutable objects with `DateTimeImmutable`, never framework date wrappers.
- **Domain exceptions** — one hierarchy rooted at `SteamApiException` for every failure.
- **Rate limit baked in** — the 100 000 requests/day quota is enforced per API key and resets at 00:00 UTC; `rateLimits` swaps in your own.
- **Timeouts and retries** — set once on `SteamConfig`; only a `5xx` or no answer at all is retried, since every attempt spends quota.
- **Hooks without the key** — `onRequest()`, `onResponse()` and `onFailure()` for logs and metrics, and `debug()` masks the key as `key=***`.
- **Your own requests** — a method the SDK does not ship is one Saloon request away, sent with the key, the budget and SDK exceptions.
- **Zero framework coupling** — plain Saloon over any `Sender` you hand it; a [Laravel bridge](https://docs.fkrzski.dev/laravel-steam-api-sdk) ships separately.

## Requirements

- PHP **8.5+**
- Saloon **4+**

## Installation

<Steps>

1. Pull the package in:

   ```bash
   composer require fkrzski/php-steam-api-sdk
   ```

2. Keep your [Steam Web API key](https://steamcommunity.com/dev) out of the source tree, or
   skip it if the [anonymous endpoints](/php-steam-api-sdk/configuration#without-an-api-key)
   are all you need:

   ```dotenv title=".env"
   STEAM_API_KEY=your-steam-web-api-key
   ```

3. Build a connector from it, and reuse that one instance — it carries the key and
   the daily budget:

   ```php title="steam.php" "$_ENV['STEAM_API_KEY']"
   use Fkrzski\SteamApiSdk\SteamConfig;
   use Fkrzski\SteamApiSdk\SteamConnector;

   $connector = new SteamConnector(new SteamConfig(
       apiKey: $_ENV['STEAM_API_KEY'],
   ));
   ```

</Steps>

<Aside type="tip" title="On Laravel?">
Skip the wiring — the [Laravel bridge](https://docs.fkrzski.dev/laravel-steam-api-sdk)
auto-discovers a `Steam` facade, reads the key from config, and shares the daily budget
through your cache store.
</Aside>

## Quickstart

```php
use Fkrzski\SteamApiSdk\ValueObjects\SteamId;

$summaries = $connector->users()->summaries([SteamId::fromSteamId64('76561198000000000')]);

echo $summaries[0]->personaName;
```

Every endpoint hangs off a resource named after its Steam interface — `players()`,
`users()`, `stats()`, `apps()`, `news()`, `webApi()` — and returns the readonly DTO straight away.
